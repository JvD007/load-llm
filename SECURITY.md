# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.3.x   | ✅ Yes     |
| < 1.3   | ❌ No      |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately by emailing:

**jaco.vandijk@outlook.com**

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

You can expect an acknowledgement within **48 hours** and a resolution or status update within **7 days**.

## Scope

The following are in scope:
- Authentication bypass or token exposure
- Remote code execution
- Sensitive data leakage (tokens, credentials)
- Dependency vulnerabilities with known CVEs

The following are out of scope:
- Vulnerabilities in third-party services (GridWeave platform, HuggingFace)
- Issues requiring physical access to the server
